What REFLEX does, in order

REFLEX runs as a hook on every tool call of your agent and asks a local daemon for a decision. The daemon works in a fixed order, and the model is the last step, not the first.

  1. Normalize The host's event becomes one canonical action, the same shape for Claude Code and for Codex: the tool, its arguments, the working directory, the repository's branch and remote, the environment.
  2. Classify Each command segment gets a side-effect class: a read, a local write, something destructive, external, financial, a credential, a privilege change, a production system. A class can be raised later and is never lowered.
  3. Redact, locally Fifteen shapes of secret are replaced by fingerprints before anything else reads the arguments. Nothing after this step sees them.
  4. Decide by policy Every rule of every source is evaluated: the team's, your own, the repository's, and REFLEX's few of its own, with an explicit precedence. Most actions are decided here, deterministically, in well under a millisecond, and no model is asked.
  5. Assess only what is open An action the policy leaves open is assessed by a model, and only if you turned one on and consented to what it is sent. Its answer is evidence; the policy's floors still hold.
  6. Record The decision is written with the rules that matched, the policy set's hash and, later, what you and the host did about it.

Beside your host, never in its place

Claude Code ships a permission classifier and a sandbox; Codex has its own approval policy. REFLEX does not replace them. It decides from a policy your team wrote and can read, before any model is asked, across hosts, and keeps the record. A sandbox contains what runs; REFLEX decides what runs. The threat model says plainly what REFLEX is not.

A team's policy, without an account

One person signs the team's policy into a snapshot and publishes it to a URL or a shared file. Every member subscribes once with the public key. From then on each daemon applies the team's rules to Claude Code and to Codex alike, a local or project policy cannot weaken a mandatory one, and a snapshot that does not verify is refused and reported, never applied.

Two hosts, one policy

REFLEX installs as a hook into Claude Code and into Codex and translates each host's events into the same canonical action, so the same policy decides for both. Claude Code's integration is verified against the real binary in the repository's tests; Codex's is built from its documentation and says so until it is verified live.
