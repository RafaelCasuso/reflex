# Fonts

Self-hosted, fetched from the Fontsource CDN as WOFF2 subsets (Latin), each
under the SIL Open Font License 1.1.

| File                                            | Family        | Author     | Role on the site                            |
| ----------------------------------------------- | ------------- | ---------- | ------------------------------------------- |
| `vt323-latin-400-normal.woff2`                  | VT323         | Peter Hull | whatever the screen shows                   |
| `ibm-plex-mono-latin-400-normal.woff2`, `-600-` | IBM Plex Mono | IBM        | the documentation and code a reader copies |

The OFL permits bundling and redistribution with software, and asks that the
fonts are not sold on their own. The licence texts are at
https://openfontlicense.org/ and in each family's repository.
